# Лабораторные работы по Python

Локальные решения ЛР1–ЛР10 по [заданиям курса](https://github.com/outtathe/python_bivt/tree/main). Git не используется, ничего не опубликовано. Задания со звёздочками исключены. Тесты добавлены там, где они требуются заданиями, в том числе ЛР7.

## Как начать

Нужен Python 3.11 или новее. Откройте терминал в этой папке:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Далее вместо `python` в командах можно использовать `.\.venv\Scripts\python.exe`; активировать среду необязательно. Скрипты с межмодульными импортами запускаются через `python -m src.labXX.module` из корня этой папки.

## Проверка

```powershell
python -m pytest -q
python -m black --check .
```

Сохранённые результаты этих команд — в отчёте ЛР7 и `images/lab07/`. Покрытие pytest-cov относится к заданию со звёздочкой и не добавлено.

## Файлы

- `src/` — простой код, функции, классы и отчёты с кодом и примерами.
- `tests/` — обязательные тесты.
- `data/` — входные файлы и фактически полученные CSV, JSON, XLSX.
- `images/` — подписанные изображения фактического вывода и его текстовые оригиналы. Это визуализации вывода, а не снимки окна терминала или Excel.

Входные данные — учебные примеры. ФИО автора и группа не указаны: личные данные не выдумывались. Запуск программ использует относительные пути, поэтому рабочая папка должна быть корнем `python_labs`.
